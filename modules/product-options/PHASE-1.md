# Product Options — فاز ۱ (متاباکس چند اسلات)

**تاریخ:** 2026-09-08  
**وابستگی:** فاز ۰

## قابلیت‌ها

روی صفحه ویرایش محصول (متاباکس «ویژگی‌های اختصاصی محصول»):

- افزودن **چند پالت** به یک محصول
- برای هر اسلات:
  - انتخاب پالت
  - برچسب نمایشی اختیاری
  - **مکان نمایش:** کنار گالری / زیر قیمت / زیر خلاصه / تمام‌عرض
  - **حالت نمایش:** مستقیم / آکاردئون / مودال AJAX
  - ترتیب با دکمه‌های ↑ ↓
  - حذف اسلات
  - **پیش‌نمایش فیلدهای پالت** (AJAX)
- ذخیره در `_ezlens_option_slots` + همگام‌سازی `_ezlens_option_template_id` (اسلات اول)

## ساختار فایل‌های جدید

```
admin/meta-box/
  class-meta-box.php     # کلاس اصلی
  views/slot-row.php     # ردیف اسلات (+ قالب JS)
  assets/meta-box.css
  assets/meta-box.js
admin/meta-box.php       # لودر سازگار با قبل
```

## نکات

- اعمال placement و display روی **فرانت** در فاز ۲ است؛ مقادیر از همین الان ذخیره می‌شوند.
- محصولات قدیمی با تک‌قالب هنگام باز شدن متاباکس مهاجرت می‌شوند.
- پیش‌نمایش AJAX برای نقش‌های `edit_products` / `manage_woocommerce` / `manage_options` مجاز است.

## تست

1. محصول → افزودن دو پالت با placement متفاوت → به‌روزرسانی
2. رفرش صفحه: هر دو اسلات و تنظیمات حفظ شده
3. postmeta: `_ezlens_option_slots` پر، `_ezlens_option_template_id` = template_id اسلات اول
4. تغییر پالت در اسلات → پیش‌نمایش فیلدها به‌روز شود
