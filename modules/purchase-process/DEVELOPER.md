# راهنمای توسعه‌دهنده — ماژول فرآیند خرید (Purchase Process)

نسخه: 1.5  
هدف: شخصی‌سازی منطق خرید/فروشگاه مثل Code Snippets، بدون دست‌کاری هسته پلاگین و تم.

## محدوده امن کار

فقط داخل این مسیر کار کنید:

```
modules/purchase-process/
```

فایل‌های اصلی:

| فایل | نقش | آیا ویرایش کنیم؟ |
|------|-----|------------------|
| `class-install.php` | جدول + storage | فقط برای باگ نصب |
| `class-ajax.php` | ذخیره/حذف/لیست | با احتیاط |
| `class-loader.php` | لود فایل‌های فعال | بسیار حساس |
| `admin/pages/*` | UI | UI فقط |
| `storage/*.php` | کدهای سفارشی فروشگاه | **محل اصلی کار روزانه** |

### نباید تغییر دهید مگر با دلیل قوی
- فایل اصلی `ezlens-secure-login.php`
- سایر ماژول‌ها (`auth`, `campaign`, `support`, ...)
- تم Woodmart / Child Theme برای منطق خرید (به‌جای آن از storage استفاده کنید)

## جریان اجرا

1. `plugins_loaded` → `maybe_install` جدول/پوشه را آماده می‌کند
2. `init` اولویت ۲۰ → Loader فایل‌های `status=1` را `include` می‌کند
3. کدهای storage مثل snippet روی کل سایت اثر می‌گذارند

## قوانین اجباری برای کد داخل storage

1. **نام تابع یکتا** با پیشوند `ezp_`
2. همیشه از `function_exists` استفاده کنید
3. **هر فایل = یک مسئولیت**
4. از تعریف ثابت/کلاس تکراری بدون چک خودداری کنید
5. قبل از فعال‌سازی، فایل را غیرفعال ذخیره و تست کنید

### نمونه امن

```php
<?php
if ( ! defined( 'ABSPATH' ) ) {
    exit;
}

if ( ! function_exists( 'ezp_product_page_custom' ) ) {
    function ezp_product_page_custom() {
        // منطق شما
    }
}

add_action( 'woocommerce_before_single_product', 'ezp_product_page_custom', 20 );
```

### نمونه خطرناک (ممنوع)

```php
function custom_product_page_render() { ... } // بدون پیشوند و بدون function_exists
```

## عنوان نمایشی vs نام فایل

- **عنوان نمایشی (`title`)**: فارسی/آزاد — فقط برای پیدا کردن در لیست
- **نام فایل (`filename`)**: انگلیسی (`product-page`) — هویت فیزیکی فایل
- بعد از ایجاد، نام فایل قفل است
- اگر نام فایل تکراری باشد ذخیره **خطا** می‌دهد (rename خودکار نداریم)

## اگر سایت ۵۰۰ شد

معمولاً از تداخل تابع بین دو فایل فعال است.

فوری:

```sql
UPDATE myutki_ezlens_purchase_scripts SET status = 0;
```

یا فقط فایل مشکل‌دار را غیرفعال کنید. سپس یکی‌یکی فعال کنید.

## افزودن قابلیت جدید به خود ماژول

1. AJAX جدید را در `class-ajax.php` ثبت کنید
2. Nonce: `ezpurchase_nonce`
3. Capability: `manage_options`
4. UI را در `admin/pages` تغییر دهید
5. Loader را فقط وقتی تغییر دهید که درباره include/امنیت باشد
